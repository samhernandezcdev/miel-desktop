Tres conceptos, uno elegido

Se evaluaron por personalidad, silueta, facilidad de animación y legibilidad a 64 px.

Elegido

A · Gota de miel

Tierna, atenta y discreta. Gota redondeada con la punta inclinada y la panza hacia un lado.

  • Pelusa festoneada, antena con punta hexagonal, halo claro
  • Capas independientes: animar es sencillo
  • 64 px: legibilidad alta, rostro con espacio para ocho expresiones

B · Pompón

Esponjosa y juguetona. Esfera peluda de borde irregular, ojos puntuales.

  • Mechón rebelde y textura de pelusa
  • Squash fácil, pero el borde peludo se anima con dificultad
  • 64 px: el borde se difumina y la cara tiene poco rango

C · Pétalo

Elegante y ágil. Cuerpo alargado, alas grandes en forma de hoja, formas angulares.

  • Contraste ámbar con índigo
  • Aleteo muy expresivo, rotaciones delicadas
  • 64 px: la cara es pequeña y las expresiones se pierden

Reglas del personaje

  1. Un solo cuerpo en forma de gota; lo que cambia entre estados es la pose, no el dibujo.
  2. Ojo derecho un poco más grande que el izquierdo.
  3. Firma visual: pelusa crema bajo la cara y antena izquierda con punta hexagonal.
  4. Dos rayas, nunca más. Sin degradados: una sombra plana y un brillo plano.
  5. Halo claro alrededor del cuerpo, antenas y patas para fondos oscuros.
  6. Movimiento ligero. Con prefers-reduced-motion se detiene todo.

Integración en React

Un solo SVG maestro con los ocho rostros; basta cambiar data-state.

import BeeRig from '@/assets/bee/bee-rig.svg?react';

export type BeeState = 'idle' | 'happy' | 'curious' | 'thinking'
  | 'sleepy' | 'surprised' | 'talking' | 'resting';

export function Bee({ state = 'idle', size = 96 }:
  { state?: BeeState; size?: number }) {
  return <BeeRig data-state={state}
    width={size} height={size} />;
}
