# Política de marca de Miel: BORRADOR / Miel trademark policy: DRAFT

> **Borrador no definitivo.** No es asesoría legal. Antes de publicarlo: confirmar quién es titular de la marca,
> revisar el nombre "Miel" en registros de marcas (México y países de distribución) y el uso de "BKODE".
> Hasta entonces no afirmes que "Miel" o "BKODE" son marcas registradas ni uses ®. Este documento **no declara registros**; solo describe cómo se espera que se use el nombre.

## Qué cubre

El nombre **Miel** (para este proyecto), su logotipo, el aspecto del personaje usado como identificador del
proyecto y el nombre del instalador. **No** limita lo que la licencia de código (MIT) y la de recursos (CC BY 4.0)
permiten sobre el código y los dibujos: aquí solo se regula **cómo usar el nombre y la identidad para identificar un
producto o servicio**.

## Usos permitidos sin pedir permiso (propuesta)

- Mencionar el proyecto por su nombre para describirlo, enlazarlo o hablar de él ("compatible con Miel", reseñas, tutoriales).
- Redistribuir el instalador oficial sin modificar, indicando su origen.
- Hacer un *fork* o una versión modificada, **siempre que** no se presente como la oficial: cambiar el nombre y la identidad visual de la versión modificada y decir que está basada en Miel.
- Usar el personaje en fan art, vídeos o proyectos propios cumpliendo la atribución de CC BY 4.0, sin sugerir respaldo oficial.

## Usos que requieren permiso por escrito (propuesta)

- Usar "Miel" o el logotipo como nombre de producto, empresa, dominio, cuenta o tienda de aplicaciones de forma que se confunda con el proyecto oficial.
- Distribuir versiones modificadas bajo el nombre "Miel".
- Afirmar o sugerir respaldo, patrocinio o afiliación oficial.
- Merchandising o productos comerciales con el logotipo como marca (el dibujo en sí está bajo CC BY 4.0; la marca no).
